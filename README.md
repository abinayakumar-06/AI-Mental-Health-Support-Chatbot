# 🧠 AI-Powered Mental Health Support Chatbot

An AI-powered chatbot designed to provide educational and supportive conversations for users who want to express their feelings, thoughts, and everyday concerns.

## ✨ Features

- 💬 Interactive AI-powered chat
- 🤖 Supportive and empathetic responses
- 🧠 Mental health awareness and emotional support
- 🗑️ Clear Chat option
- ⚡ Simple and user-friendly interface
- 🌐 Built with Streamlit

## 🛠️ Technologies Used

- Python
- Streamlit
- OpenAI API

## 📁 Project Structure

```text
AI-Mental-Health-Support-Chatbot/
│
├── app.py

⚙️ Installation
1. Clone the repository
git clone https://github.com/abinayakumar-06/AI-Mental-Health-Support-Chatbot.git

2. Open the project folder
cd AI-Mental-Health-Support-Chatbot

3. Install the required packages
pip install -r requirements.txt

🔑 API Key Setup
Create the following file:
.streamlit/secrets.toml

Add your API key:
OPENAI_API_KEY = "your-api-key-here"

▶️ Run the Application
Run the following command:
streamlit run app.py
The application will open in your browser at:
http://localhost:8501

🎯 Purpose

This project is developed for educational and supportive purposes. It demonstrates how AI and Streamlit can be combined to create an interactive conversational application.
