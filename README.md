## 📌 About the Project

The **AI-Powered Mental Health Support Chatbot** is a conversational AI application designed to provide **empathetic and supportive responses** to users experiencing everyday emotional difficulties.

The chatbot uses **Natural Language Processing (NLP) and Generative AI** to understand user messages and provide helpful, compassionate responses.

It is designed as a **mental wellness support tool**, not as a replacement for professional medical or psychological care.

---

## 🎯 Objectives

* Provide an accessible conversational support system
* Understand user messages using AI
* Generate empathetic and supportive responses
* Encourage positive mental wellness practices
* Provide a simple and user-friendly interface
* Promote awareness of the importance of professional help when needed

---

## ✨ Key Features

### 💬 AI Conversation

Users can communicate naturally with the chatbot and receive AI-generated responses.

### 🧠 Empathetic Responses

The chatbot is designed to respond in a compassionate, supportive, and non-judgmental manner.

### 🤖 Generative AI

The application uses an AI language model to generate contextual responses based on the user's conversation.

### 🌐 Interactive Web Interface

Built using **Streamlit** for a simple and interactive web-based experience.

### 🔒 API Key Protection

The API key is stored securely using environment variables instead of directly exposing it in the source code.

### ⚠️ Safety-Oriented Responses

The chatbot does not claim to diagnose mental health conditions or prescribe medication.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/abinayakumar-06/AI-Powered-Mental-Health-Support-Chatbot.git
```

### 2. Navigate to the Project

```bash
cd AI-Powered-Mental-Health-Support-Chatbot
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Configure the API Key

Create an environment file and add your API key securely.

```text
OPENAI_API_KEY=your_api_key_here
```

⚠️ **Never upload your API key to GitHub.**

### 6. Run the Application

```bash
streamlit run app.py
```

The application will open in your browser.
